☁️ Sincronización en la nube

Usa JSONBin.io (gratuito) para compartir datos entre dispositivos y administradores.

Pasos:
1. Regístrate en jsonbin.io (gratis)
2. Ve a API Keys → copia tu Master Key
3. Ve a Bins → "Create Bin" con contenido {}
4. Copia el Bin ID y pégalo abajo
5. Guarda → los datos se sincronizan automáticamente entre todos los dispositivos
